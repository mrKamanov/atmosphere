# Политика конфиденциальности

**Приложение «Атмосфера»**  
Дата вступления в силу: 30.05.2026 · обновлено: 24.10.2026  
Разработчик: **Сергей Каманов**  
Контакт: mr.kamanov@yandex.ru

## 1. Общие положения

Приложение «Атмосфера» предназначено для учёта дисциплины и вовлечённости учеников в школе.
Мы уважаем конфиденциальность пользователей и персональных данных учеников.

## 2. Какие данные обрабатываются

На устройстве пользователя могут храниться:

- фамилия и имя учеников;
- класс, идентификатор ученика;
- отметки о поведении на уроках (поощрения и замечания);
- расписание, классы, уведомления;
- фамилия учителя (для подписи в отчётах);
- имя пользователя в настройках (по желанию).

## 3. Где хранятся данные

Данные хранятся **локально** на вашем устройстве (база данных приложения).
Разработчик **не предоставляет облачный сервер** и **не получает** доступ к вашим данным автоматически.

## 4. Передача данных третьим лицам

Приложение само по себе **не отправляет** данные на серверы разработчика.

Данные могут покинуть устройство только если вы сами:

- экспортируете отчёт и отправите его (мессенджер, почта, «Файлы»);
- передадите файл другому пользователю «Атмосферы» (например, завучу);
- отправите отчёт завучу по локальной сети Wi-Fi (см. раздел 5).

Резервное копирование средствами Android для приложения отключено: данные не попадают
в облачные копии Google или производителя телефона.

**Файлы отчётов (.atmo).** Отчёт упаковывается в собственный формат приложения: обычные программы
(Excel, архиваторы, просмотрщики) его не открывают. Это **не является полноценным шифрованием** —
файл содержит фамилии и имена учеников и их отметки. Передавайте его только адресату (завучу)
и удаляйте из мессенджеров и почты после загрузки.

Ответственность за дальнейшую передачу файлов лежит на пользователе и в рамках политик выбранных сервисов.

## 5. Обмен между устройствами по локальной сети

В приложении есть передача отчёта от учителя к завучу **напрямую по школьной сети Wi-Fi**
(без интернета, облака и серверов разработчика).

- Передача возможна только между устройствами в одной локальной сети (обычно один Wi-Fi роутер).
- Приём включается вручную на устройстве завуча и выключается при выходе с экрана приёма.
- Каждый входящий файл показывается завучу в диалоге с именем отправителя и принимается
  **только после подтверждения на экране завуча**.
- Данные не выходят за пределы школьной сети и не отправляются разработчику.
- Трафик внутри локальной сети **не шифруется** (обычный HTTP): он может быть виден
  администратору сети. Используйте только доверенную школьную сеть.

## 6. Разрешения приложения

- **Уведомления** — напоминания о собраниях и уроках (включаются в настройках).
- **Сеть и Wi-Fi** — обмен отчётами между устройствами по локальной сети. Соединение
  с интернетом приложению не требуется и им не используется.

## 7. Срок хранения и удаление

Данные хранятся, пока они есть в приложении. Вы можете удалить отметки, архив или все данные
в разделе **Настройки → Данные**. Удаление приложения с устройства удаляет локальную базу данных.

## 8. Дети и школьные данные

Приложение используется педагогами и администрацией школы. Ввод персональных данных учеников
должен соответствовать правилам вашей образовательной организации и законодательству РФ
о персональных данных (152-ФЗ), включая получение необходимых согласий, если они требуются.
