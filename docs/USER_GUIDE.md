# Атмосфера — инструкция пользователя

## Общее описание

«Атмосфера» — мобильный журнал дисциплины для школы.
Учитель отмечает поведение на уроке за пару секунд, завуч собирает сводку по классам и ученикам.
Приложение работает без интернета: данные хранятся только на вашем устройстве.

**Для учителя:** классы, ученики и расписание — вручную или из файла. На уроке — быстрая отметка за поведение. Баланс по ученикам, напоминания об уроках и собраниях, экспорт отчётов.

**Для завуча:** импорт отчётов от учителей, аналитика по школе, классу и ученику, наглядные графики, экспорт в HTML и PDF, поиск ученика по фамилии.

**Безопасность:** нет облака и сервера разработчика. ФИО и отметки не уходят в сеть автоматически. Обмен — зашифрованными файлами, которые вы сами отправляете через мессенджер или почту.

---

## Первый запуск

1. Откройте **Настройки** (иконка шестерёнки в правом верхнем углу).
2. В поле **«Ваше имя»** введите, как к вам обращаться — например, «Сергей Дмитриевич».
3. В поле **«Ваша фамилия в отчёте»** введите фамилию, которую увидит завуч в файле — например, «Каманов».
4. Нажмите иконку **человека** в правом верхнем углу главного экрана, чтобы переключиться между режимом учителя и завуча.

---

## Часть 1. Учитель

### Главный экран

На главном экране — четыре карточки:

- **Урок** — кнопка для перехода к ближайшему уроку. Под ней — информация о следующем уроке: день, время, предмет, класс.
- **Мои классы** — список ваших классов. Нажмите на класс — откроется его карточка. Нажмите «+» — добавьте новый.
- **Мои ученики** — общее число учеников. Нажмите, чтобы перейти к полному списку.
- **Родительские собрания** — ближайшее собрание и количество предстоящих.

В верхнем правом углу — три иконки: смена роли (человек), уведомления (колокольчик), настройки (шестерёнка).

---

### Классы

**Добавить класс:**
1. На главном экране нажмите блок «Мои классы».
2. Нажмите зелёную кнопку «+» в правом нижнем углу.
3. Введите обозначение класса — например, «5-А» или «9-Л».
4. Нажмите «Добавить».

**Удалить класс:**
1. Откройте карточку класса.
2. Нажмите иконку корзины в правом верхнем углу.

> При удалении класса ученики не удаляются — они остаются в общем списке.

---

### Ученики

#### Добавить ученика вручную

1. На главном экране нажмите «Мои ученики».
2. Нажмите зелёную кнопку «+» в правом нижнем углу.
3. Введите фамилию и имя ученика.
4. Выберите класс из выпадающего списка.
5. Нажмите «Добавить».

#### Загрузить учеников из файла «Моя школа»

1. Откройте «Мои ученики».
2. Нажмите иконку «⋮» (три точки) в правом верхнем углу.
3. Выберите **«Загрузить из Моя школа»**.
4. Выберите Excel-файл с расписанием из программы «Моя школа».

Приложение само распознает класс по имени файла. Важно, чтобы имя файла содержало обозначение класса — например:
- `9-Л.xlsx`
- `9 Л 2025-26.xlsx`
- `5Б 2024-25.xlsx`

Если приложение не смогло определить класс, появится сообщение с советом переименовать файл.

#### Загрузить учеников из шаблона

1. Скачайте шаблон: нажмите «⋮» → **«Скачать шаблон»**. Сохраните файл «Ученики_шаблон.xlsx» на телефон.
2. Откройте файл в Excel или Google Sheets.
3. Заполните три столбца: **Фамилия**, **Имя**, **Класс**. Пример:

| Фамилия | Имя | Класс |
|---|---|---|
| Иванов | Пётр | 5-А |
| Петрова | Мария | 5-А |

4. Сохраните файл.
5. Вернитесь в приложение: нажмите «⋮» → **«Загрузить из шаблона»** → выберите заполненный файл.

#### Действия с учениками

Откройте список учеников. У каждого ученика есть кнопки:

- **Тап на карточку** — откроется профиль с полной историей отметок.
- **«Перевести»** — перевести ученика в другой класс. Выберите новый класс из списка и подтвердите.
- **Иконка корзины** — удалить ученика. Появится выбор:
  - **«Архивировать»** — ученик скроется из активного списка, но история останется.
  - **«Удалить навсегда»** — ученик и вся история будут безвозвратно удалены.

#### Фильтры и поиск

Над списком учеников:
- **Строка поиска** — ищет по фамилии, имени или классу.
- **Чипы «Активные» / «Архив» / «Все»** — переключают отображение.

---

### Расписание

#### Открыть расписание

На главном экране нажмите карточку с расписанием. Или: нажмите «⋮» → **«Расписание»**.

Вверху — чипы с днями недели (Пн–Сб). Нажмите на день или свайпните влево/вправо, чтобы переключиться.

#### Добавить урок

1. Нажмите зелёную кнопку «+» в правом нижнем углу.
2. Заполните поля:
   - **Начало** — время начала урока (например, 09:00).
   - **Конец** — время окончания. Можно выбрать длительность кнопками (30, 35, 40 или 45 минут).
   - **Предмет** — название предмета (например, «Математика»).
   - **Класс** — выберите из списка созданных классов или введите вручную.
3. Нажмите «Сохранить».

> Если уроки пересекаются по времени, приложение покажет предупреждение.

#### Загрузить расписание из файла

1. Нажмите «⋮» в правом верхнем углу экрана расписания.
2. Выберите один из вариантов:
   - **«Скачать шаблон»** — сохранит пустой Excel-файл. Заполните его и загрузите обратно.
   - **«Загрузить из шаблона»** — загрузите заполненный шаблон.
   - **«Загрузить из «Моя школа»»** — загрузите расписание из программы «Моя школа».

#### Важно: привязка урока к классу после загрузки

После загрузки расписания из «Моя школа» приложение создаст записи уроков с названиями классов из файла. Однако чтобы на уроке отображался список учеников, нужно убедиться, что класс в записи расписания совпадает с классом, в котором есть ученики.

**Порядок действий:**

1. Загрузите расписание из «Моя школа».
2. Импортируйте учеников (вручную, из шаблона или также из «Моя школа»).
3. Откройте расписание и проверьте каждый урок:
   - Нажмите на карточку урока → нажмите иконку **карандаша**.
   - В поле **«Класс»** убедитесь, что выбран правильный класс. Если название класса в расписании не совпадает с тем, как он создан в приложении — выберите нужный класс из списка или введите вручную.
   - Нажмите **«Сохранить»**.

> Если класс в расписании и класс учеников называются по-разному (например, «9-Л» в расписании и «9Л» у учеников), список учеников на уроке будет пустым. Приведите названия к единому виду.

#### Открыть урок из расписания

Нажмите на карточку урока в списке. Откроется экран с классом.

#### Редактировать или удалить урок

На карточке урока — две иконки:
- **Карандаш** — отредактировать время, предмет или класс.
- **Корзина** — удалить урок.

---

### Урок: отметки поведения

1. Откройте урок из расписания или нажмите кнопку **«Урок»** на главном экране.
2. На экране — сетка карточек учеников. Можно менять масштаб жестом «раздвинуть пальцы» (pinch-to-zoom).

#### Как ставить отметку

1. **Коротко нажмите** на ученика. Внизу появится шторка с вариантами отметок.
2. Нажмите нужный вариант — отметка мгновенно запишется.

#### Варианты отметок

**Положительные:**
- **Старается** (+1) — ученик включается в работу.
- **Помощь классу** (+1) — помогает одноклассникам.
- **Прогресс** (+1) — улучшение за период.
- **Примерное поведение** (+1) — ведёт себя безупречно.

**Отрицательные:**
- **Срыв дисциплины** (−1) — нарушает ход урока.
- **Гаджет на уроке** (−1) — пользуется телефоном без разрешения.
- **Опоздание** (−1) — опоздал на урок.
- **Не готов** (−1) — нет нужных материалов.
- **Драка** (−1) — конфликт с одноклассниками.
- **Ненормативная лексика** (−1) — грубые слова.

После выбора нажмите **«Готово»**, чтобы закрыть шторку.

#### Профиль ученика

**Долгий тап** на ученика — откроется его профиль.

В профиле:
- **Карточки «Хорошо» и «Нарушения»** — общее количество положительных и отрицательных отметок.
- **Частые нарушения** — три самых частых типа нарушений.
- **По предметам** — диаграмма баллов по каждому предмету.
- **Лента событий** — все отметки с датой, предметом, типом и влиянием на балл.

**Действия в профиле:**
- **Удалить отметку** — иконка корзины рядом с записью.
- **Очистить всё** — иконка «Очистить» в верхней панели. Удалит все отметки ученика.
- **Выгрузить** — иконка «↓» в верхней панели. Выберите период и создайте отчёт по ученику.

---

### Напоминания

В настройках можно включить три типа напоминаний:

- **Напоминания о собраниях** — приложение напомнит за день и за 3 часа до собрания.
- **Напоминания об уроках** — если после урока не поставлено ни одной отметки, приложение напомнит.
- **Системные уведомления** — уведомления будут приходить даже когда приложение закрыто. При первом включении запросит разрешение.

---

### Родительские собрания

#### Открыть календарь

На главном экране нажмите «Родительские собрания».

Календарь показывает месяц. На датах — зелёные точки или цифры: количество собраний на этот день.

#### Добавить собрание

1. Выберите дату в календаре.
2. Нажмите зелёную кнопку «+» в правом нижнем углу.
3. Заполните поля:
   - **Тема** — по умолчанию «Родительское собрание». Можно изменить.
   - **Класс** — выберите из списка.
   - **Время** — час и минуты. По умолчанию 18:00.
   - **Заметки** — необязательное поле (до 500 символов). Например, повестка собрания.
4. Нажмите **«Добавить»**.

#### Просмотр и редактирование

- Нажмите на карточку собрания — откроются детали: дата, время, класс, заметки.
- Нажмите **«Редактировать»** — измените любое поле.
- Нажмите **«Удалить»** — собрание удалится.

---

### Отправка отчёта завучу

Это главный способ передачи данных от учителя к завучу.

#### Как создать и отправить отчёт

1. Откройте **Настройки** (иконка шестерёнки).
2. В блоке **«Отправить отчёт завучу»** выберите, что хотите выгрузить:
   - **Все мои классы** — отметки по всем классам из вашего расписания.
   - **Все мои отметки** — все отметки на этом телефоне.
   - **Один предмет** — выберите предмет из выпадающего списка.
3. Выберите период: **День**, **Неделя**, **Месяц** или **Учебный год**.
4. Можно переключить тогл «Текущий период» в положение «Выкл» и выбрать конкретную дату в календаре.
5. Нажмите **«Создать отчёт»**.
6. Появится диалог с итогами: сколько отметок попало в отчёт.
7. Нажмите **«Отправить»** — поделитесь файлом через мессенджер, почту или Bluetooth.
8. Можно также нажать **«Сохранить»** — файл останется в памяти устройства.

> Файл имеет расширение `.atmo` и зашифрован. Открывается только в приложении «Атмосфера» на устройстве завуча.

#### Профиль ученика: выгрузка одного ученика

1. Откройте профиль ученика (долгий тап на ученика в списке или на уроке).
2. Нажмите иконку **«↓»** (выгрузить) в правом верхнем углу.
3. Выберите период и нажмите **«Создать отчёт»**.
4. Отправьте файл завучу.

## Часть 2. Завуч

### Переключение в режим завуча

На главном экране нажмите иконку **человека** в правом верхнем углу. Откроется дашборд завуча. Нажмите ещё раз — вернётесь к режиму учителя.

### Импорт отчётов от учителей

1. Попросите учителей выслать вам файлы отчётов (формат `.atmo`).
2. Сохраните файлы на телефон.
3. На экране завуча нажмите иконку **«↑»** (загрузить) в правом верхнем углу.
4. Выберите один или несколько файлов.
5. Приложение загрузит и обработает их автоматически.

**Управление источниками данных:**

В блоке **«Источники данных»** на дашборде:
- Каждый загруженный отчёт отображается в списке.
- **Включить/выключить переключатель** — включить или исключить данные из сводки. Данные при этом не удаляются.
- **Удалить** — убрать отчёт из списка.

Также можно включить **«Мои отметки»** — данные, введённые на устройстве завуча.

### Дашборд завуча

Дашборд — это главный экран в режиме завуча. Вот что на нём есть, сверху вниз:

**Выбор периода:**
- Чипы **«Неделя»**, **«Месяц»**, **«Произвольный»**.
- При выборе «Произвольный» открывается календарь. Выберите начальную и конечную дату и нажмите «Применить».

**Сводка:**
- Краткая статистика по школе за выбранный период.

**Динамика периода:**
- График изменения баллов по неделям. Показывает тенденцию: становится лучше или хуже.

**Рейтинг классов:**
- Таблица классов, отсортированная по баллу. Нажмите на класс — откроется подробный анализ.

**Сравнение параллелей:**
- Сравнение средних баллов по параллелям. Работает, когда загружены данные двух и более параллелей.

**По классам и дням:**
- Тепловая карта. Классы — по вертикали, дни недели — по горизонтали. Цвет показывает балл.

**Ритм недели:**
- Диаграмма распределения баллов по дням недели. Показывает, в какие дни ученики ведут себя лучше.

**Ученики:**
- **«Кого похвалить»** — ученики с лучшими показателями за период.
- **«Кому уделить внимание»** — ученики, которым нужна помощь.

**Тезисы для педсовета:**
- Краткие выводы для выступления. Можно использовать как основу для доклада.

**Поиск ученика:**
- Введите фамилию или имя. Откроется карточка с аналитикой по ученику за выбранный период.

### Анализ класса

1. В «Рейтинге классов» нажмите на класс.
2. Откроется экран с:
   - Общим баллом класса.
   - Динамикой по дням и неделям.
   - Топ-нарушениями и топ-поощрениями.
   - Балансом по предметам.
   - Списком учеников с их баллами.
   - Нажмите на ученика — откроется его профиль.

### Экспорт отчётов

**Экспорт школы:**
1. На дашборде нажмите иконку **«↓»** в правом верхнем углу.
2. Сохраните или отправьте отчёт по всей школе.

**Экспорт класса:**
1. Откройте класс → нажмите иконку **«↓»**.
2. Сохраните или отправьте отчёт по классу.

**Экспорт ученика:**
1. Откройте профиль ученика → нажмите иконку **«↓»**.
2. Сохраните или отправьте отчёт по ученику.

Все экспортные отчёты доступны в форматах **HTML** и **PDF**:
- **HTML** — открывается в браузере, удобно для просмотра на экране.
- **PDF** — подходит для печати, отправки по почте или архивации.

## Настройки

Откройте иконку шестерёнки в правом верхнем углу.

### Профиль
- **Ваше имя** — как к вам обращаться.
- **Ваша фамилия в отчёте** — фамилия, которую увидит завуч.

### Уведомления
- **Напоминания о собраниях** — за день и за 3 часа до собрания.
- **Напоминания об уроках** — после завершения урока без отметок.
- **Системные уведомления** — показывать даже когда приложение закрыто.

### Отправить отчёт завучу
См. раздел «Отправка отчёта завучу» выше.

### Данные
- **Очистить все отметки** — удалить баллы всех учеников по всем предметам. Классы, ученики и расписание сохранятся.
- **Очистить архив** — удалить архивных учеников и старые уведомления.
- **Удалить все данные** — полный сброс приложения. Это действие необратимо.

---

## Полезные советы

- **Быстрый старт для учителя:** добавьте класс → добавьте учеников (вручную или из файла) → добавьте уроки в расписание → проверьте, что классы в расписании совпадают с классами учеников → начните отмечать на уроке.
- **Имя файла для импорта:** при загрузке из «Моя школа» убедитесь, что имя файла содержит обозначение класса — например, `9-Л.xlsx`.
- **Резервная копия:** регулярно отправляйте отчёты завучу — это также служит резервной копией ваших данных.
- **Архивация:** при переводе ученика используйте архивацию вместо удаления — история останется.
- **Для завуча:** начните с загрузки отчётов учителей. Дашборд покажет общую картину сразу. Для детального разбора — нажмите на класс или найдите ученика через поиск.
